## Featured Work

### 🔬 AI Predictive Maintenance for Rolling-Element Bearings

<table>
<tr>
<td width="60%" valign="top">

My current research project investigates whether machine-learning methods can improve vibration-based bearing condition monitoring beyond conventional RMS thresholds.

The project combines **mechanical engineering, signal processing, machine learning, reliability engineering, and experimental validation** using the CWRU and NASA IMS bearing datasets.

**Highlights**
- Leakage-aware validation across operating conditions
- Classical ML fault detection and multiclass diagnosis
- Chronological anomaly detection on run-to-failure data
- Sensitivity analysis and engineering interpretation
- Reproducible notebooks, figures, results, and research manuscript

**[Explore the full project →](https://github.com/daksheshftw/AI-Predictive-Maintenance)**
